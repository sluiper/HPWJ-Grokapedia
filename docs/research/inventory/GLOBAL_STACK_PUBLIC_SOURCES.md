## 4. Class A/B energy metric (AU) vs Anabeeb pressure classes

**AU public definition uses power-like product:** pressure (bar) × flow (L/min) = bar·L/min.  
- Class A: 800–5600  
- Class B: >5600  

**Anabeeb / OPS-P-019** uses pressure bands (LP/HP/UHP) and **absolute ceiling MCR-046**.  
**Do not** silently replace Anabeeb pressure classes with AU Class A/B without a mapped conversion table and human gate.  
**Action:** Document both systems in Sec21 / training awareness; control SSOT remains MCR.

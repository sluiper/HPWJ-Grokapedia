# ATC-HPWJ-AWARE — Course Specification  
## مواصفات الدورة — التوعية بأعمال النفث المائي عالي الضغط

**MCR Controls Referenced:** MCR-016, 023, 027, 038, 043, 047, 051  

| Field | English | العربية |
|-------|---------|---------|
| Code | ATC-HPWJ-AWARE | ATC-HPWJ-AWARE |
| Name | HPWJ Awareness | التوعية بأعمال النفث المائي عالي الضغط |
| Duration | ½ day (3–4 h) | نصف يوم (3–4 ساعات) |
| Audience | Site personnel near HPWJ work | أفراد الموقع قرب أعمال HPWJ |
| Does **not** qualify | Unsupervised operation | التشغيل دون إشراف |
| Pass | Attendance + quiz ≥70% | حضور + اختبار ≥70% |
| Output | Attendance card (awareness) | بطاقة حضور (توعية) |
| Validity | 24 months recommended refresh | يُنصح بالتجديد كل 24 شهراً |

### Learning outcomes / مخرجات التعلم
1. Recognise HPWJ exclusion and never enter unauthorised (MCR-051).  
2. Understand injection injury is a medical emergency (MCR-043 / Ch10).  
3. Know stop-work authority applies to everyone (MCR-038).  
4. Know only competent certified operators may operate (MCR-030).  
5. Know Anabeeb minimum team context (MCR-047) at awareness level.

# ATC-HPWJ-OP-001 — Trainer Guide / Script

**MCR Controls Referenced:** MCR-005, 006, 009, 010, 016, 017, 019, 020, 021, 023, 025, 027, 028, 030, 031, 033, 038, 039, 043, 046, 047, 048, 050, 051, 052  

**Audience:** ATC Trainer / Assessor (Level 5 path or audited Level 4+)  
**Class size:** Max 8–10  

---

## Absolute trainer rules

1. **Formulas and constants:** Open or project `MASTER_CONTROL_REGISTER.md` row **MCR-017**. Never write a free-floating metric/imperial constant on a whiteboard that is not labelled “per MCR-017”.  
2. **Thresholds:** When stating Anabeeb absolutes, say the MCR-ID first (e.g. “per MCR-051…”).  
3. **SSOT cards:** Use live appendices/templates for field tools — do not invent a second RF table.  
4. **Stop-work modelling:** Demonstrate and reward stop-work (MCR-038).  
5. **No self-grading language** about the course quality.

| 6 | 45 | Barricading & exclusion: SABIC baseline vs Anabeeb unauthorised rule (MCR-027/031/051) |

### Learning outcomes (must exit Day 1 with)

- State why small puncture wounds after HPWJ exposure are emergencies.  
- Name high-priority MCR items and Anabeeb rows 047, 048, 051.  
- Complete a supervised pre-use inspection to MCR-023 standard.  
- Calculate RF using **MCR-017** and apply **all three** MCR-016 controls.  
- Present Medical Alert Card and verbal emergency script.

### Trainer scripts (samples)

**Stop-work (MCR-038):**  
“If you see a control missing — whip check, AWD, wrong disc, person inside exclusion — you stop. You do not need permission. We will support you.”

**RF (MCR-016/017):**  
“Open MCR-017. Read the imperial and metric formulas from the register. Do not use a number from memory. Then check all three additive controls in MCR-016.”

**Anabeeb team (MCR-047):**  
“Anabeeb minimum team size and dedicated emergency-stop duty when line of sight is lost — read MCR-047 aloud. Compare to SABIC two-person baseline. We use the stricter Anabeeb rule.”

| Block | Min | Content |

### Learning outcomes

- Inspect and manage hoses/fittings/whip checks to MCR.  
- Install/verify AWD; confirm tip mark per MCR-052.  
- Operate shotgun only within MCR-050; prove RF via MCR-017.  
- Demonstrate team composition and dump communication.  
- Verify rupture disc rating rule per MCR-048 / 009.

### Critical coaching points

- **Never bypass AWD** on flex lance (MCR-020).  
- After any plunger change thought-experiment: re-verify ratings (MCR-015) — link to Sec17.  
- Shotgun: if any MCR-050 limit would be exceeded → stop, reconfigure, or select different method (MCR-039).

### Field Verification conduct

- Assessor uses `03_Practical_Competency_Checklist.md` only.  
- Critical items: **pass/fail**, no partial credit.  
- Item 3 (RF): learner must show calculation using **MCR-017** source.  
- Item 14 (shotgun): if shotgun not performed, mark **N/A with justification** only if course RA excludes live shotgun — then assess knowledge of MCR-050 limits verbally + dry setup; prefer live water practice when safe.  
- Failed critical item → document; re-assessment per ATC policy before certificate.

### Theory exam conduct

- Closed book except **allowed**: blank paper + **printed MCR extract** (high-priority + 046–052 + 016/017) so constants are looked up correctly.  
- Time: ~60 minutes for full bank subset (see exam bank).  
- Pass ≥80%.

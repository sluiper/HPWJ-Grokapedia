**MCR Controls Referenced:** MCR-016, 017, 019, 020, 023, 030, 038, 043, 047, 048, 050, 051, 052, 064  

| Field | English | العربية |
|-------|---------|---------|
| Code | ATC-HPWJ-VOC | ATC-HPWJ-VOC |
| Name | Verification of Competency / Refresher | التحقق من الكفاءة / التجديد |
| Duration | 1 day | يوم واحد |
| Entry | Current or recently expired Level 2+ card, or VOC trigger | بطاقة مستوى 2+ أو محفّز VOC |
| Pass | Practical critical items + short theory ≥80% + behavioural | عملي + نظري ≥80% + سلوكي |
| Output | VOC stamp / renewed validity (24 months) | ختم VOC / تجديد 24 شهراً |
| Fail | No renewal; remediation plan | لا تجديد؛ خطة معالجة |

### VOC triggers (Ch13) / محفّزات التحقق
- Every 24 months (hard)  
- After LTI / high-potential incident  
- New high-risk equipment/process  
- Absence from HPWJ work >6 months  
- Client request / quality non-conformance

# ATC-HPWJ-UHP — Trainer Guide  
## دليل المدرب — UHP

**MCR Controls Referenced:** MCR-034, 016, 017, 019, 020, 031, 039, 043, 047, 051, 052  

**Prerequisite:** Verify OP-001 current. Class size max 6.  
**Primary field card:** `docs/appendices/Appendix_J_UHP_Creeping_Hose_Card.md`

---

## Absolute rules
1. **No free-floating RF constants** — MCR-017 only.  
2. Any **No** on MCR-034 absolute table → **do not start**.  
3. Model hierarchy of methods (MCR-039) before accepting manual UHP.  
4. Live water practical only under elevated RA; dry stations acceptable for AWD/tip-mark if pressure RA forbids.

---

## Day structure (1-day intensive / expand to 2 with more practical)

| Block | Min | Content |
|-------|-----|---------|
| 0 | 20 | Safety; Level 3 vs Level 2 boundary |
| 1 | 40 | Why UHP is different: energy, hose life, back-out fatality patterns (Sec25 Case themes) |
| 2 | 40 | MCR-034 absolute table walkthrough (App J) |
| 3 | 40 | RF workshop via MCR-017 + three controls; UHP examples from App C (cite only) |
| 4 | 50 | AWD install station + tip mark measure (MCR-019/020/052) |
| 5 | 30 | Vacuum at outlet / debris control; no QC in high-movement (MCR-007) |
| 6 | 30 | Exclusion layout UHP band + MCR-051 |
| 7 | 40 | Team roles: three persons + dump when LOS lost (MCR-047) |
| 8 | 40 | Hierarchy exercise: when to refuse manual and call Bundle Blaster / automation (MCR-039) |
| 9 | 45 | Emergency drill: loss of control / back-out / injection script |
| 10 | 60 | Practical assessment (`03_UHP_Practical_Checklist.md`) |
| 11 | 40 | Theory short + endorsement records |

### 2-day expansion
- Day 1: theory + dry stations  
- Day 2: water practicals + assessment + exam

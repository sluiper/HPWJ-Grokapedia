# ATC-HPWJ-AUTO — Trainer Guide (Overview)

**MCR Controls Referenced:** MCR-021, 039, 023, 010  

### Outcomes
1. State hierarchy of methods (MCR-039) and when automation is reasonably practicable.  
2. Pre-use / interlock / auto-shut-off checks (MCR-021).  
3. Zoning and non-essential exclusion when automation runs.  
4. Route learners into method endorsement day(s).  

### Timing (½ day overview)

| Block | Min | Content |
|-------|-----|---------|
| 0 | 15 | Safety; Level 2 vs Level 3 method stamps |
| 1 | 30 | MCR-039 workshop + Anabeeb preference for operators outside jetting area |
| 2 | 40 | Sensor / interlock / emergency dump (MCR-021 / 010) |
| 3 | 30 | Failure modes: bypass, sensor defeat, SIMOPS with auto tools |
| 4 | 30 | OEM landscape (Hammelmann xPRO, StoneAge automation, Peinemann/DERC themes — descriptive) |
| 5 | 25 | Path to LTC/IBC/OBC days; assessment model |

### Rules
- Never teach defeating interlocks.  
- Any residual manual RF control still uses **MCR-017**.
